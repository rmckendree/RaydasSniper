# ============================================================================
# AUTHENTICATION probes — bearer token / JWT  (non-destructive)
# ----------------------------------------------------------------------------
# Fuzz the BEARER TOKEN value (the {{token}} variable, or the value after
# "Bearer " in the Authorization header). Each line is a token to try against a
# normally-protected endpoint.
#
# The sample JWTs below are STRUCTURAL probes with a fake signature and a benign
# payload (sub=FZcanary). A correctly-built API rejects every one of them. The
# FINDING is the opposite:
#   401 / 403            -> authN enforced (good — expected for all of these)
#   200 WITH real data   -> BROKEN authentication. Record it and stop.
# Pay special attention to the alg:none line (accepting it = classic JWT bypass)
# and the tampered-role line (accepting it = signature not verified).
#
# Also test the two cases that aren't token *values* (do these by hand, since
# they change the request shape, not the token string):
#   - remove the Authorization header entirely
#   - send the header with no scheme / no value
# Lines starting with "# " (or a lone #) are comments and are skipped.
# ============================================================================
